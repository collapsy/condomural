# CondoMural

CondoMural é uma plataforma web mobile-first para centralizar, organizar e preservar comunicações e informações oficiais de condomínios residenciais.

O primeiro tenant real é o **Cidade Mooca Vila Palermo**, cuja experiência local poderá utilizar o nome **Central Palermo**.

> **CondoMural é o produto. Central Palermo é a experiência do primeiro condomínio.**

## Objetivo

Criar uma fonte oficial, organizada, persistente e fácil de consultar para informações do condomínio. Canais como WhatsApp podem continuar sendo utilizados para divulgação, enquanto o CondoMural mantém a informação oficial e seu histórico.

## Princípios

- mobile-first e responsivo;
- simplicidade e acessibilidade;
- qualidade e testabilidade desde o início;
- segurança, LGPD e minimização de dados;
- administração autônoma;
- responsável técnico separado da responsabilidade editorial;
- configuração em vez de hardcode quando fizer sentido;
- preservação do histórico e auditoria de ações sensíveis;
- Palermo como primeiro tenant, não como arquitetura do produto;
- projetar para evoluir e implementar somente o necessário.
